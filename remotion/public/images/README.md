# Gerçek görseller

Bu klasöre `manifest.json` içindeki dosya adlarıyla fotoğrafları koy.
Dosya yoksa ilgili sahne otomatik olarak stilize bir yer tutucu çizer; video yine de render edilir.

Kontrol: `npm run check-assets`

Lisans notu: Wikimedia Commons'taki CC BY-SA görsellerde fotoğrafçı adını ve lisansı
video açıklamasına yaz ("Fotoğraf: Nevit Dilmen, CC BY-SA 3.0" gibi).
